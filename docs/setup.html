Hearth

Setup guide

Google requires a one-time registration before any app can reach a Nest thermostat. This takes about 15 minutes and a $5 fee paid to Google. Hearth's setup window follows the same steps and links to each page.

Before you start

  • Use the Google account that owns the thermostat. It is the one you use in the Google Home or Nest app.
  • Install Hearth and open it. The setup window opens on first launch. Later, find it in the panel's ... menu under Account and Settings.
  • You will end up with three values: a Project ID, a Client ID and a Client Secret.

Google Cloud

Create the sign-in client

  1. Create an OAuth client

    Open Google Auth Platform, Clients. Pick an existing project or create one.

    • If Google asks you to configure the consent screen first, choose External for the audience and fill in an app name and your email.
    • Application type: Desktop app. Name it Hearth. Click Create.
    • Copy the Client ID and Client Secret, or click Download JSON. Hearth can read that file.

  2. Enable the Smart Device Management API

    Open the API page, check that the project picker shows the same project as your client, and click Enable.

  3. Add yourself as a test user

    Open Audience and add your Google account under Test users. Without this, Google blocks the sign-in.

Device Access

Link the client to your Nest

  1. Register for Device Access

    Open the Device Access console, accept the terms and pay the one-time $5 fee.

  2. Create a project

    • Give it any name.
    • Paste your OAuth Client ID when asked.
    • Leave Enable events off. Hearth refreshes on its own and does not need Pub/Sub.
    • Click Create project.

  3. Copy the Project ID

    It looks like 1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d.

Hearth

Connect and sign in

  1. Enter your credentials

    In the setup window, go to Credentials. Copy each value and click Paste. Hearth works out which field it belongs in. You can also drop the client JSON file on the window. Each field shows a check when the value looks right.

  2. Sign in with Google

    Your browser opens. Pick your account. If Google says the app is unverified, click Advanced, then continue. This is your own project, so that warning is expected.

  3. Turn on your thermostat

    On the Nest permissions screen, select your home and turn on each thermostat you want to control. Approve. The browser shows a success page and Hearth lists the thermostats it found.

Avoid signing in every week. While your consent screen is in Testing, Google ends the sign-in after 7 days. To stop that, open Audience and click Publish app. It stays unverified, which is fine for personal use.

Troubleshooting

If something goes wrong

No thermostats show up

The thermostat was not turned on in the Nest permissions screen. Use Fix Permissions in the setup window, or Change Thermostat Access in Account and Settings, and turn it on.

"Access blocked"

Your account is not a test user, or the app is not published. Add yourself on the Audience page and sign in again.

"Invalid client"

Check the Client ID and Secret, and that the client type is Desktop app. A new client can take a few minutes to start working.

Signed out after a week

The consent screen is still in Testing. Publish it, then sign in again.

Still stuck

Email support@hearthbar.app with the message Hearth showed you.
